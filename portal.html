Accounts & Secure Sync

This is the secure-account entry point. Cloud sign-in is activated only after the school's authentication and database service is configured.

Privacy by design

  • This page does not collect or store passwords.
  • Local classroom data remains available without an online account.
  • Cloud student records are disabled until authentication, database permissions, and role-based access rules are configured and tested.
  • Never place private service keys in this public GitHub repository.
